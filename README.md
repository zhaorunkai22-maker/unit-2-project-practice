# RPG Character & Inventory Project

## Description
This Python project demonstrates basic object-oriented programming:

- Characters: `Wizard` and `Warrior`  
- Inventory system to hold items like `Weapon` and `Potion`  
- Each character can attack using weapons or basic attacks  

## How to Run
1. Make sure you have Python 3 installed  
2. Run the program in `demo.py`:

```bash
python demo.py
```
